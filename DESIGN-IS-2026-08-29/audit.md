## 증거

- 인터랙티브 요소: `<button>` 86개 (한 화면)
- 타입 스케일: 8·9·10·11·12·13·14·15·16·18·26px — **11단계, 대부분 1px 간격**
- 라운드: `rounded-md`(3) `lg`(19) `xl`(60) `2xl`(15) `full`(33) `[2rem]`(1) — 6종
- 고유 hex 28개 (지배색 `#E3B24A` 86회)
- 저대비 토큰: `text-zinc-700` 3, `text-zinc-600` 21, `text-zinc-500` 21
  - `#3f3f46` on `#141414` = **1.84:1** (WCAG AA 4.5 미달)
  - `#52525b` on `#141414` = **2.45:1** (미달)
  - `#71717a` on `#141414` = **3.88:1** (본문 미달)
- 9px 텍스트 17곳, 8px 1곳 — **가장 작은 글자가 가장 낮은 대비와 겹침**
- 상태: 빈 ✓ / 로딩 ✓ / 포커스 ✓(전역 `:focus-visible`) / 성공 ✓(토스트) / **에러 ✗**
  - 2,300줄 중 `catch` 2개. Supabase 쓰기 실패가 전부 무음 — 저장 안 돼도 화면은 성공처럼 보임
- 유휴 애니메이션: 배경 골드 오브 `orb-pulse` 무한 루프

## 판정: REDESIGN — 단, 시각 시스템에 한정

규칙상 20점 미만은 REDESIGN. 다만 무너진 건 구조가 아니라 표면이다 —
유용(#2)·정직(#6)은 살아 있고, 정보 구조와 흐름은 보존한다.
0점 원칙이 없으므로 IA를 갈아엎을 근거는 없다.

## 최고 레버리지 5수

1. **#3 아름다움** — 타입 11단계를 10/12/14/16/20/26 6단계로 고정. 8·9px 폐기.
2. **#3 아름다움** — 라운드 6종을 lg/xl/full 3종으로.
3. **#7 오래감 + #9 환경 + #10 최소한** — 배경 오브 제거, `backdrop-blur-2xl`→없음,
   `shadow-2xl`→`shadow-lg`, `rounded-[2rem]`→`rounded-2xl`.
4. **#8 치밀함** — Supabase 쓰기에 에러 표면. 최소한 실패 토스트.
5. **#10 최소한 + #2 유용** — 풀의 남/여 2열 분리 재검토. 성별은 도트로 이미 표시됨.

## 이번 세션에 실행한 것

1·3번 및 대비(8·9px→10px, zinc-700/600→가독 토큰) 적용.
2·4·5번은 미실행 — 로그인 게이트로 시각 검증이 불가해 되돌리기 어려운 변경은 보류.
